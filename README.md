# Game Dev on Linux

This repository holds a [wiki](https://github.com/peeweek/GamedevOnLinux/wiki) that compiles resources and experience I gathered in order to shift my game development workflow on linux.

## Objectives

The final objective is to reproduce the workflow I had on windows with alternatives on linux or pseudo-emulation of software (generally using wine). It is not a test but rather an attempt to move the workflow as daily driver on linux. 

This is based on my sole experience, and is an ever-work-in-progress research project. It features findings and scripts that I figured out of trial and error. I will try to note as much as I can all the quirks you can expect while using these software.
